### In a nutshell

OnedataFileRESTClient is a Python client to the Onedata file REST API. It offers basic
operations on files as a concise, low-level library.

Supported Onezone versions: `>= 21.02.5` Supported Oneprovider versions: `>= 21.02.5`.

For more, see the [GitHub][] and [PyPI][].
